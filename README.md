# Data Exploration Project – Program Investment Analysis

This project involves data exploration and analysis of a dataset containing investment and project details such as programs, physical addresses, collaborators, approval dates, regions, and financial commitments.
##  Project Overview

The dataset includes columns such as:

- Program  
- Round  
- Project Title  
- Physical Address (Suburb, Post Code)  
- University Collaborator  
- Other Partners  
- Primary Location of Activity  
- Approval Date  
- RAP Region and State Electorate  
- Actual Contractual Commitment (in $)
##  Objectives

- Understand the structure and features of the investment/project dataset  
- Clean and prepare the data for analysis  
- Identify trends and distributions in funding and project locations  
- Visualize key aspects such as location, financial commitment, and collaborations
 ##  Technologies Used

- **Python**  
- **Jupyter Notebook**
##  Key Analysis Tasks

- Data cleaning and preprocessing  
- Exploratory Data Analysis (EDA)  
- Grouping and aggregating investment values  
- Visualizing project distribution by suburb, region, and collaborators
